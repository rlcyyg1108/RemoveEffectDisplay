# Remove Effect Display（移除效果显示）

一个纯客户端模组。  
用于去除状态效果带来的视觉干扰。  

**目前支持的 Minecraft 版本**：1.20.1 forge  

## 功能

 - 隐藏背包右侧效果列表  
 - 隐藏 HUD 右上角效果图标  
 - 禁用效果粒子  

***

# Remove Effect Display

A client-side mod that removes visual clutter caused by status effects.

**Supported Minecraft version**: 1.20.1 Forge

## Features

- Hide the effect list on the right side of the inventory
- Hide effect icons in the top-right corner of the HUD
- Disable effect particles
